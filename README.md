# 🌐 Modern Portfolio – React.js

### 🎨 A sleek, responsive portfolio website built with **React.js** and **Tailwind CSS**, designed to showcase your projects, skills, and achievements in a modern and elegant way.

---

## 🚀 Features

- ✨ **Dark & Light Mode** – Eye-friendly toggle for all-day viewing  
- 💻 **Fully Responsive** – Works beautifully on mobile, tablet, and desktop  
- ⚡ **Smooth Animations** – Hover and floating effects for engaging UX  
- 📬 **Email Integration** – Contact form powered by [EmailJS](https://www.emailjs.com)  
- 🧩 **Reusable Components** – Easy to customize and scale

## ⚙️ Installation & Setup

1️⃣ Clone this repository  
```bash
git clone https://github.com/Vk02u/modern-portfolio-react.git
````

2️⃣ Move into the project folder

```bash
cd modern-portfolio-react
```

3️⃣ Install dependencies

```bash
npm install
```

4️⃣ Run the app locally

```bash
npm start
```

➡️ Your app will run on: [http://localhost:3000](http://localhost:3000)

---

## 📂 Build for Production

```bash
npm run build
```

✅ The optimized files will be available in the `/build` folder.
